How to read this board

  • Implied value is this entry's own claim about what a launch would be worth if the protocol's record stayed as it is. It does not predict whether or when a token is issued.
  • Records no token is DefiLlama's record, never proof a protocol has no token. A protocol on the watchlist may still have a token its DefiLlama record does not carry.
  • The value band on each row is ±1 walk-forward log-RMSE — about ×8 either way. The typical miss is large; the band says so in plain numbers instead of hiding it.
  • Verdicts are by implied value within this board: FARM is the top decile, THIN the next 40%, SKIP the rest — and any protocol bleeding 40% or more of TVL in a week is SKIP whatever its value, because the capital is leaving.
  • Farm cost is the all-in cost of the plan: the capital in the position plus the gas to set it up and to act weekly while it is held. The break-even line in each detail view assumes, only as an assumption, that 5% of supply goes to farmers.
  • Set aside, not hidden: protocols above the $50M floor that the house rule leaves out are wrapped, staked or bridged products of tokens that trade; protocols below the floor that fail the rule are exchanges, versioned pools or the same kind of product. They are counted in the strip above, with the reason.
